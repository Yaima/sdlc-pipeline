Color roles

Material 3 roles. The pipeline semantics (--sdlc-*) map onto them, so a retheme changes the reference palette at the top of tokens.css and everything follows. Every pair the components use passes WCAG 2.2 AA in both themes; check-contrast.py verifies it.

Type scale

Manrope for the interface (the AgentTrust ID brand face), IBM Plex Mono only for values that are code: slugs, hashes, commands. Body line length stays under 80 characters.

Chips, buttons, states

Status is a shape, a color, and a word, following the convention shared by GitLab, GitHub Actions, and Argo CD: check passed, cross failed, dot running, pause waiting on a person, circle not started. Targets are 24px minimum for chips and 44px for buttons.
